# 附录 C · 恐惧速查表

心里在怕，先翻这一页。中栏是这本书里对应到哪一章哪一节，右栏是一件今天就能做、几乎不花钱的事。怕不是错，几十年前没人教过我们怎么谈这些；把怕说清楚、再落到一件小事上，这页就够本了。

| 怕什么 | 翻到哪一章哪一节 | 今天能做的一件事 |
|---|---|---|
| 怕摔倒，摔了就完了 | 第5章 5.4、5.5、5.11 | 把家里（卫生间门口、玄关、床边）的地垫全撤出去——不是收起来，是撤出这个家（第5章 5.16） |
| 怕失禁，出门丢人 | 第10章 10.2–10.4、10.9 | 做一组盆底肌训练：假装憋尿、憋屁收紧的那块肌肉，收紧五秒、放松五秒，做十次（第10章 10.11） |
| 怕忘事，变成痴呆 | 第9章 9.2、9.4 | 拿"忘的是事，还是功能"这条线对一遍自己或爸妈；分不清，就挂一次记忆门诊或神经内科，进门说"记性变差，想查有没有能治的原因" |
| 怕夜里一个人在家出事 | 第4章 4.7；第8章 8.9、8.10；第10章 10.8 | 把第8章那张判断表打印成大字，贴在电话旁，填上地址、社区电话、子女和邻居的号码 |
| 怕老伴先走，之后的日子 | 第4章 4.5、4.6；第11章 11.7；第22章 22.2 | 给一个真能说上话的老友打个电话，当场约下下次见面或通话的固定日子 |
| 怕饭都做不动 | 第12章 12.9、12.10 | 打电话问社区居委会：这一片有没有助餐点、我这种情况有没有补贴、走不动时能不能送餐上门 |
| 怕看病没人陪 | 第17章 17.4；第4章 4.9 | 去社区卫生服务中心问一次：家庭医生怎么签、签了管什么、多少钱 |
| 怕被子女嫌弃 | 第20章 20.4、20.13 | 把那句"我想跟你聊聊我对以后的想法，今天先不做决定"说出口，或发出去 |
| 怕家里为钱和照护翻脸 | 第20章 20.7、20.10；第22章 22.6 | 先列一份清单，标清哪些是夫妻共有、哪些是一个人的；再定一条家规——大额转账隔 24 小时再办 |
| 怕拖累子女 | 第4章 4.4、4.5 | 查一次你所在的城市有没有长期护理保险，失能评估和待遇怎么申请（参保地医保局） |
| 怕钱不够，生场大病就塌 | 第4章 4.2–4.4；第14章 14.8–14.10 | 用"掌上 12333"查清养老保险缴了多少年、个人账户有多少，弄清自己坐在第几层 |
| 怕被骗（含 AI 假亲人） | 第18章 18.6–18.13；第1章 1.7 | 和家人定一条规矩：大额转账隔 24 小时再办；凡"现在就交钱、过了今天就没了"的，先停一天、再找一个人说一遍 |
| 怕手机上的事办不成 | 第18章 18.2–18.5；第0章 | 今天跑通一个动作——挂号，或付款，把它做成一次；跑不通，就问社区有没有代帮办 |
| 怕"抱团"最后翻脸 | 第15章 15.5、15.6；第4章 4.5 | 先看一眼关系账：你能叫动的名单还剩谁，挑一个人，今天续上一次 |
| 怕失去决定权，被当孩子哄 | 第20章 20.11、20.13；第21章 21.2、21.4 | 找到那个在你做不了主时替你说话的人，问他一句愿不愿意（第21章 21.10） |
| 怕疼着死，死得没尊严 | 第21章 21.2、21.3、21.5、21.7 | 先写下"现在最想保住的是什么"，再开始想"到了那一程，更愿意在家里，还是医院" |

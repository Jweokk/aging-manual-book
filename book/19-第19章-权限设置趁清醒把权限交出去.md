# 第 19 章 权限设置：趁清醒把权限交出去

你今天能自己签住院同意书，能自己取钱，能自己决定这个刀开不开。这些事看着是你的，其实靠的是同一件东西——你名下那份"我说了算"的资格。

这份资格不是终身的。一次脑梗、一次事故，或一点点退下去的记性，都能把它拿走，不发通知。它走了以后，家里会面对一个问题：往后谁替你做主。你早写好了答案，就按你写的办；没写，就按法律排的顺序办。

## 19.1 这一章解决什么问题

签字、取钱、住院、卖房、开通一个手机号——这些事，法律认的是"本人"的意思。你头脑清楚时，你说了算。

麻烦在于，"本人"这个身份会消失，还不打招呼：人在，但认不出家人、说不清话、签不了字时，只有两种结果——你早写好了谁替你做主，就按你写的办；没写，就按法律排的顺序办。

这一章讲的就是那个空当：趁你还清醒，把"谁替我做主"，从法律的默认答案换成你自己的答案。

## 19.2 失能之后再想补办，很多手续补不上

- **要花多少**：今天不花钱；拖到补办，花的是来回跑的时间和几趟路（钱：花不了几个钱｜工夫：半天｜力气：不费｜要开口吗：好开口）
- **简单说**：意定监护、遗嘱、委托，都有一个共同前提——办的时候你得是"完全民事行为能力人"，也就是你清楚自己在签什么。一旦被认定认不清了，你亲手补办这条路基本就关了，只剩法院指定这条更慢、更伤感情的路。
- **可以怎么做**：把"趁清醒"当成一个时间点：六十多岁、身体还行时办，是常规做法。等出现失智苗头再办，公证处会反复核实你是不是真明白，不少人到这一步就卡住了。
- **来源**：A｜这是法律对"行为能力"的硬要求（《民法典》第 33 条、第 21 条），不是公证处为难人。**但是**，各地公证机构对老年人意思能力的审查宽严不一，没有全国统一尺度：同一个老人，这家公证处反复核实，那家可能一次就办下。"基本办不了"这句是就趋势而言，不是一刀切。
- 特别提醒：**对谁成立**——对现在能自己做主的成年人成立。已确诊明显失智的，这一节不再适用，看 19.10。
- **换回来的**：体面＋关系——不再怕"决定权被人拿走"
- **在中国怎么落地**：去当地公证处问意定监护、遗嘱公证怎么办；补办困难时走法院（见 19.10）。以当地最新口径为准。

## 19.3 意定监护：趁清醒，给自己指定一个替你说话的人

- **要花多少**：一到两次公证（钱：几百元到数千元，各地差异大｜工夫：半天到一天｜力气：不费｜要开口吗：好开口）
- **简单说**：意定监护，说人话就是——趁你还清楚，你和一个信得过的人（也可以是机构）签一份书面约定：哪天我认不清了、签不了字了，就由你来替我说话、替我做决定。《民法典》第 33 条就是干这个的。
- **可以怎么做**：① 先选定人（见 19.4）；② 两个人一起到公证处，说要办"意定监护协议公证"；③ 把该约的约进去：什么情况下生效、能管哪些事（医疗决定、钱、日常照料）、怎么改、怎么撤；④ 公证书各自留一份，家里文件袋放复印件。
- **来源**：A｜《民法典》第 33 条写明：完全民事行为能力的成年人，可用书面形式，与近亲属或其他愿意担任监护人的个人、组织事先商定，等自己丧失或部分丧失民事行为能力时，由这个人履行监护职责。**但是**，它管的是失能之后的监护，不等于现在就授权对方动你的钱，也压不过你当场说出的意思。
- 特别提醒：**对谁成立**——对现在能自己签字的人成立。丁克、再婚、失独、家里关系紧的家庭办得较多，因为它把"法律默认排给谁"换成了"我自己挑谁"。监护人可以是个人，也可以是组织。
- **换回来的**：体面＋关系——不再怕"到了那天没人替我说得上话"
- **在中国怎么落地**：去当地公证处办"意定监护协议公证"，双方带身份证、户口簿等身份材料，涉财产处分的带财产凭证（如房产证），再带上你们商量好的协议文本，公证员审核后可帮你改、也可代拟。去哪问、要多少钱：先打当地公证处电话问价，或上中国公证网、司法部政务服务平台查。以当地最新口径为准。

## 19.4 挑代理人，看四条

- **要花多少**：一次认真想清楚，一次当面问对方（钱：不用花｜工夫：一次长谈｜力气：不费｜要开口吗：得开口，有点难为情，要开口求人）
- **简单说**：意定监护挑的不是"最有钱的"或"官最大的"，是"到时候真能把话说到、还能按你的意思说"的人。挑错了比没挑更麻烦。
- **可以怎么做**：四条对着看——
  1. **肯听你的，不替你拿主意。** 当面问他："万一我糊涂了，我说不治，你会照办吗？"
  2. **有那份力气，也在场。** 能来得及时、跑得动手续。八十岁的老伴，未必接得住。
  3. **跟你钱没关系，或关系摊得开。** 事先问清：哪天他替你管钱，谁来盯他。
  4. **留一个替补。** 约好"他不行了，换谁"。
- **来源**：C｜这四条是通行做法，也是公证审查里常看的点（意思真实、有没有能力、有没有利益冲突）；**但**哪条最要紧因人而异，没有研究能给统一答案。
- 特别提醒：**对谁成立**——对身边还有得挑的人成立。一个人也信不过的，可以把事拆开：钱交给机构管，人身照护留给亲属。
- **换回来的**：关系＋体面——不再怕"所托非人"、"为争这点东西，一家人翻脸"
- **在中国怎么落地**：对着这四条去和公证员聊一次；涉及钱的职责，事先约定谁监督、怎么查。以当地最新口径为准。

## 19.5 生前预嘱：深圳写的是"尊重"，不是"必须执行"

- **要花多少**：一次长谈，加一次公证或见证（钱：公证几百元｜工夫：半天｜力气：不费｜要开口吗：难开口，要说清"到时候别抢救我"）
- **简单说**：生前预嘱，是趁你清醒，把"到最后要不要插管、要不要心肺复苏、要不要进 ICU"写下来。目前全国只有深圳有专门规定；**深圳的写法是：医疗机构在那种时候实施医疗措施，应当尊重患者的意思表示——是"尊重"，不是"必须执行"。** 它没写"医院必须照办"；也不是安乐死，说的是要不要那套创伤性抢救。
- **可以怎么做**：① 和家里人、常看的医生把上面那几句谈开；② 书面写下来；③ 找明确依据就问当地卫生健康委或大医院安宁疗护科；深圳可找深圳市生前预嘱推广协会名录。④ 深圳以外，可以照北京生前预嘱推广协会的“我的五个愿望”来写——那是国内流传最广的一份可填模板，“选择与尊严”网站能在线填写、打印（2009 年用到现在）。
- **来源**：A｜有法规原文（《深圳经济特区医疗条例》第 78 条）。**但是**，深圳以外没有专门立法；一份写得清楚、有人见证、随时能拿出来的意愿书，只是"软保证"，帮医生和家人知道你怎么想，不是硬保证。
- 特别提醒：**对谁成立**——对还能交流、自己做主的人成立。深圳要求：经公证，或两名以上非救治人员见证，书面、录音录像都行。
- **换回来的**：体面——不再怕"疼着、被机器拖着、家人为救我吵翻"
- **在中国怎么落地**：谈、写、公证或见证；去当地卫生健康委或大医院安宁疗护科问。以当地最新口径为准。跟医疗决定有关的，见第 22 章。

## 19.6 遗嘱怎样立才不作废

- **要花多少**：自书不花钱；打印遗嘱一百到几百元；公证遗嘱几百元，80 岁及以上老人首次办免收服务费（发改价格〔2021〕1081 号）（工夫：半天｜力气：不费｜要开口吗：好开口）
- **简单说**：遗嘱作废，多数不是因为你写错了给谁，是形式没做对。常见几个原因：见证人找得不对（比如让一个将来要分遗产的人来当见证）；漏签日期、漏签名；打印遗嘱没在每一页签；签字时被人劝着改。
- **可以怎么做**：形式挑一种做足——自书要亲笔手写、签名、注明年月日；代书、打印都要两个以上见证人，打印的还要遗嘱人和见证人在**每一页**签名、注明年月日；怕麻烦就去公证处办遗嘱公证。
- **来源**：A｜法条原文（《民法典》第 1134–1139 条）。**但是**，立了好几份、内容打架的，以最后一份为准（第 1142 条）；受欺诈、胁迫所立的遗嘱无效（第 1143 条）；遗嘱还得给"缺乏劳动能力又没有生活来源"的继承人留必要份额（第 1141 条）。
- 特别提醒：**对谁成立**——对脑子清楚、能自己表达的人成立。内容写具体：哪套房、哪个账户给谁。
- **换回来的**：关系＋钱——不再怕"我写的东西最后不算数"
- **在中国怎么落地**：自己写，或去公证处办遗嘱公证（80 岁及以上首次免费）；拿不准的问公证处或律师。以当地最新口径为准。

## 19.7 家庭索引表：一张纸，让全家找得到

- **要花多少**：一支笔、半小时（钱：不用花｜工夫：半小时｜力气：不费｜要开口吗：好开口）
- **简单说**：最怕的不是东西没有，是"东西在哪儿只有你一个人知道"。你一进医院，全家翻箱倒柜，保单、房本、银行卡、公证文件全找不着。解法很土——写一张索引表。
- **可以怎么做**：照这个表填，写完念给一个家人听，让他知道它在哪。
  | 类别 | 具体 | 放在哪 | 谁知道 | 紧急时怎么取 |
  | 证件 | 身份证、户口簿、房本 | | | |
  | 钱 | 银行卡、存折、保单、基金证券 | | | |
  | 法律文件 | 意定监护、遗嘱、生前预嘱、委托书 | | | |
  | 钥匙与密码 | 保险柜、家里备用钥匙 | | 密码只写提示 | |
  | 人和机构 | 主治医生、社区、律师、公证员 | | | |
- **来源**：C｜本书整理的实操办法，不含数据；急诊室里"一页纸省下几分钟"是共识。
- 特别提醒：**对谁成立**——对所有家里有重要文件的人成立。**密码别整条写在表上**：真密码单独交给一个信得过的人。
- **换回来的**：关系＋体面——不再怕"我走后，家里人连东西在哪都不知道"
- **在中国怎么落地**：需要时，把这张表和 19.3、19.5、19.6 的文件装进同一个文件袋，固定放一个位置。以当地最新口径为准。

## 19.8 数字遗产：手机号、微信支付宝、银行卡、云相册

- **要花多少**：一次查询或一次公证（钱：手机号过户可能要做公证，几百元｜工夫：几天到几周｜力气：不费｜要开口吗：好开口）
- **简单说**：人走了，手机里还留着钱和账号，这几样要分开看。**手机号**：号码归国家，你用的是"使用权"，法院和公证处已认可它可继承，办完公证或拿到法院文书，去运营商办过户。**微信、支付宝里的零钱和余额**：可以依法提取；账号本身归平台——多数平台协议写明账号所有权归平台、用户只有使用权，所以一般不能继承、不能过户。
- **可以怎么做**：① **手机号**——继承人协商一致（或法院裁判），办继承公证或拿调解书，再去运营商营业厅过户；② **微信、QQ 零钱**——用继承人实名的微信号，进【我】→【服务】→【钱包】→【客服中心】，输入"微信支付财产继承"，按指引提交材料；③ **支付宝**——打支付宝官方客服热线 95188，或在支付宝搜索"遗产继承"，说明要办"余额/资金继承"，按指引提交材料，具体入口和材料以页面当时展示为准；④ **银行卡**——先查再取，小额可简化（见第 23 章）；⑤ **密码和账号**——别把真密码整条写在纸上，用带“紧急联系人／紧急访问”功能的密码管理器（1Password、Bitwarden 这一类），把主密码封好、交给一个信得过的人；清单上只写“有哪些账号、存在哪一类工具里”。本书与任何软件商无利益关系。
- **来源**：A｜手机号和微信、QQ 零钱都有官方口径（司法部智慧普法平台转载的人民法院报、广东省司法厅；腾讯客服 2026 年 4 月）。**但是**，云相册、游戏账号、自媒体账号、数字藏品怎么处理，全国没有统一规定，《民法典》第 127 条只做了原则性保护，具体规则以各家平台的服务协议为准，而且常改。这几样，去平台客服问；记着“以平台当时的规则为准”。另外，主流密码管理器都提供紧急联系人／紧急访问（各家叫法不同），以产品当时的说明为准；这一条属于通行做法（C 档）。
- 特别提醒：**对谁成立**——这条更多写给家属；但**你**现在能做的，是把账号、绑定的银行卡、常用平台列进 19.7 那张表。
- **换回来的**：钱＋关系——不再怕"人在钱在，人走了钱不知道在哪"
- **在中国怎么落地**：运营商营业厅、银行网点、微信和支付宝里的继承通道；公证去公证处；卡住了打 12345。以当地和平台最新口径为准。

## 19.9 办这些要花多少钱、跑几趟

- **要花多少**：下面是量级，各地差别大（钱：几十元到上千元｜工夫：几次半天｜力气：不费｜要开口吗：好开口）
- **简单说**：一张账，让你心里有数，不用被"必须公证"吓住。
  - **意定监护协议公证**：没有全国统一价，各地差得远。有的公证处按小时协商收费（例如某地公开价目是 500–1000 元/小时，配套事项另计），有的按件协商、最低到数千元一件。多少钱、怎么收，打当地公证处电话问最准。
  - **遗嘱公证**：几百元；80 岁及以上老人首次办免收服务费。
  - **房产继承公证**：费率第一档不超过 0.5%，单套住宅费用总额原则上不超过 1 万元。
  - **跑几趟**：意定监护、遗嘱公证通常一到两次；房产继承看有没有争议，可能好几趟。
- **来源**：A｜收费全国不统一，依据是《公证服务收费管理办法》和 2021 年两部门的价格指导意见（发改价格〔2021〕1081 号）；意定监护这类多是市场调节价、由各公证处自定，具体到你那家，得打电话问。
- 特别提醒：**对谁成立**——对要花钱办这些事的家庭成立。低保户、重度残疾人办基本公证，减免不低于 50%，办前问一句"能不能减"。
- **换回来的**：钱——不再怕"办个事被来回加价、来回跑"
- **在中国怎么落地**：先打当地公证处电话，问价格、问要带什么；对价格有疑问，找价格或司法行政部门。以当地最新口径为准。

## 19.10 已经失能了，只剩法院这条路

- **要花多少**：一次特别程序诉讼，可能要司法鉴定（钱：鉴定费几千元，各地不同｜工夫：几个月｜力气：家属来回跑｜要开口吗：好开口）
- **简单说**：如果没来得及办意定监护，人已经认不清、签不了字了，要让"谁替他做主"生效，就得走法院——由近亲属等利害关系人或有关组织，向他的住所地基层法院申请，宣告他为无民事行为能力人或限制民事行为能力人，再由法院指定监护人。
- **可以怎么做**：① 由近亲属或有关组织向住所地基层法院提出申请；② 法院按特别程序审理，常要做行为能力鉴定；③ 判决后指定监护人；④ 情况好转、原因消除了，还能申请撤销原判决。
- **来源**：A｜法条和解释写明（《民法典》第 24 条、《民事诉讼法》第 194 条；最高人民法院 2023 年答复）。**但是**，指定谁容易变成亲属之间争；法院判的是"最有利于被监护人"，会看你备好的材料，和到底谁在真正照顾。
- 特别提醒：**对谁成立**——对已失能、又没提前安排的人及其家属成立。**这一节就是上节的理由**：走法院慢、贵、还伤感情；能不走的前提是趁清醒先把 19.3 办掉。
- **换回来的**：关系＋体面——不再怕"人都糊涂了，家里人为谁说了算闹上法庭"
- **在中国怎么落地**：去住所地基层法院立案庭，问申请材料、问鉴定怎么做；拿不准的问律师或打 12348。以当地最新口径为准。

## 19.11 如果你是在替爸妈看

这件事他们多半不会主动提，你提。开场别从"以后您糊涂了"入手，从你自己入手："我想趁现在都清楚，把我自己的事定一定，也想请你们帮我拿个主意。"

一次只问一件。今天只问一句："如果有一天您自己说不了话，谁替您说最放心？"剩下的下次再问。

你真正能马上做的，是不用他点头的三件：把他的用药、诊断、常去医院做成一页纸；把 19.7 那张索引表替他填起来——哪怕他不配合，你自己先摸清东西在哪；陪他去一次公证处或医院，先问清楚，再说服。

他若不谈，别硬碰。意定监护、遗嘱、生前预嘱都有"软"的做法：先把他的想法记下来，先把该问的机构问到。

最后一句丑话，语气放平：这些事，越早办越简单。越晚办，那个还能替你留出做主空间的人，可能自己先不自在了。

## 19.12 今天只能做的一件事

打开手机备忘录，或者抽一张纸，写下这一行：

> "如果我有一天说不了话、签不了字，我希望由 ______ 来替我做主。"

填一个名字。今天不办任何手续，只把这一个人定下来。名字有了，19.3 那道门才算有了入口。

## 19.13 本章我不确定的地方

- 各地公证机构对老年人"意思能力"的审查标准不统一，宽严尺度没有全国统一文件，实践中差别较大——这正是本章反复提醒"趁清醒早办"的原因；具体能不能办、卡在哪，要去当地公证处问。
- 意定监护协议公证的收费，多地属市场调节价、由各公证处自定，各地差异极大（本章给了两个公证处的公开价目作参照，但不是全国标准），办前一律打当地公证处电话问价。
- 云相册、游戏账号、自媒体账号、数字藏品怎么处理，全国没有统一规定：《民法典》第 127 条只是原则性保护，我们翻到的主流平台协议里，多数写明"账号所有权归平台、不得转让继承"。这几样只能去平台客服问，以平台当时的规则为准。这一条已有可查的官方梳理（广州市司法局转载《人民日报》报道，见 19.14），不再标"待核"；但结论仍是——没有统一规则，只有一句"去平台问"。
- 〔待核〕微信、支付宝里亲人的钱怎么提，入口和材料以平台页面当时展示为准——这两条钉不到长期不动的官方页：微信目前走继承人实名微信号的"我 → 服务 → 钱包 → 客服中心"，输入"微信支付财产继承"（腾讯客服 2026-04 有公开说明）；支付宝目前是拨官方客服热线 95188、或在 App 内搜"遗产继承"说明情况（95188 见支付宝服务大厅"联系我们"页）。平台一改这页就对不上，办前先在 App 里搜一次或打客服电话确认。

本章给的收费和跑腿次数只是量级；公证与法院的流程细节各地不一，办前一律打电话问当地公证处、法院立案庭。

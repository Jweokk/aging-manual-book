## 一、裁决：主线只留一条，其余降级成"层"

上一轮我们的 v0.1 用"变老时间线四格"当主线。外部提纲给出了两条替代轴，一并比较：

| 候选主线 | 主张 | 裁决 |
|---|---|---|
| **A 时间线四格**（我们 v0.1）：你现在站在变老的哪一格 | 读者按**自己的位置**找入口 | ✅ **当主线** |
| B 说明书流程轴：先看这一页→安全须知→拆箱→日常保养→故障自检→权限密码→售后→报废 | 读者按**碰到的问题**找入口 | ⬇️ 降级为**装置层**（第 0 章怎么用 + 全书统一栏目 + 症状速查表）——它解决"怎么查"，不解决"从哪开始" |
| C 四账户/四资源轴：身体·金钱·关系·尊严 | 读者按**哪笔账该补**找入口 | ⬇️ 降级为**评判层**（每个办法末尾一行"这笔投入买的是哪一样"） |

**为什么不能三轴并用当主线**：一章只容得下一个开场句。三条轴同时上，每章开场句式就会打架，读者第三次翻页就找不到坐标——那正是"罗列感"的来源。

**四格保留，但吸收分龄段的精确度**：格一 还没老（40–60，也含 30+ 自认还年轻的人）／格二 刚变老（身体开始给信号）／格三 开始要人帮／格四 最后一段。

**吸收四账户，改写为"四样资源，各算各的，不互相折算"**（外部提纲里最好的一条）：

| 这本书帮你留住的 | 是什么 |
|---|---|
| **自理年限** | 能自己吃饭、上厕所、洗澡、出门的年数——**不是寿命本身** |
| **体面** | 不被当孩子哄、不在人前失态、还能自己拿主意 |
| **钱** | 自己的养老钱，和子女被牵扯进去的钱 |
| **家人的时间与精力** | 照护者的损耗——中国家庭最贵、过去没人算进来的一笔账 |

> **诚实性条款（写进第 0 章）**：四样各算各的，**不折算**。"少摔一跤"和"每月省 300 元"不在同一把尺子上。
> 这条同时锁死了"高性价比"这三个字被滥用的空间。

## 二、体例：五栏 + 分档 + 四条写作纪律（本轮吸收最实的一块）

每个办法统一写成五栏：

```
### 换鞋凳是防跌倒最便宜的一件家具

- 要花多少：200–400 元，一次搞定；不需要向任何人解释你为什么需要它
  （钱：低｜时间：一次｜体力：低｜面子：零）
- 简单说：站着穿鞋比坐着穿鞋更容易摔。卫生间和玄关是老年家里摔倒最多的两个地方。
- 怎么做：①有靠背、不带轮；②旁边墙上装一根竖向扶手；③鞋架抬到不用弯腰的高度
- 来源：B（老年病学界通行建议，缺随机试验，但有明确的跌倒地点分布数据）
- 特别提醒：轮椅使用者要的是另一套高度，见 __。**争议**：没有研究证明换鞋凳单独降低了跌倒率，
  它通常作为居家改造组合的一部分起效。
- 在中国怎么落地：改造补贴见附录 A；自己找人做要问哪三句话见 __
```

**分档（沿用既有活书分档，加两栏）**

- A｜有具体数字可查：荟萃分析、大型队列或随机对照试验；或引到法条、官方文件原文
- B｜有研究支持但说不出确切数字；或小样本、单项研究
- C｜作者经验、访谈得来的公认做法——直接标"公认做法"，不冒充证据
- **（新增）争议栏**：有反方证据或适用条件限制的，明确写出，不许藏
- **（新增）适用人群必标**：60 岁健康人／75 岁共病／已失能——适用人群不同必须分开写
- 沿用既有五档口径（官方口径／第三方验证／厂商宣称／本书实测／未标），**"未标"计数必须为 0**

**四条写作纪律（全文通用）**

1. 标题一律动词或名词短语开头，**不用"关爱""呵护""温馨""夕阳红"这类词**。
2. **不写"定期体检""适量运动"这种没法执行的废话**——要么给频次、时长、强度，要么不写。
3. 涉及钱：**写人民币数字**；涉及政策：**写"怎么办 + 去哪问"**，并注明"以当地最新口径为准"。
4. 案例框只放**真实、可署名、可给出处**的案例；核不到出处的只能标"侧写"，且**不得当证据用**（沿用既有的外部稿纪律）。

## 三、骨架：序 + 第 0 章 + 5 篇 / 22 章 + 结语 + 附录

### 第 0 章 这份说明书怎么用
- 我是谁、为什么写这本书、**我不是医生**（非处方声明与免责边界）
- 四样资源，各算各的不折算
- 每条怎么看：五栏分别回答什么
- **如果你只有十分钟：现在就做的三件事**
- 怎么查：按症状（附录 C）／按钱／按"我自己用还是替爸妈查"
- 什么时候这本书不适用：急症、已明确诊断、急诊，先看医生

### 序 · 老年人就是我们未来的样子

### 篇一 · 存本钱：还没老的时候〔格一〕
> 扉页句：决定你 80 岁摔不摔得断髋骨的那几步，是你 14 岁在操场上跑的。

1. **变老不是某一天发生的**（含：四个型号别混用——衰弱／肌少症／共病／失能；发病率压缩；五个误会，其中"这是老了，正常"最危险；焦虑生意）
2. **骨本与肌肉本**（骨密度、日照与维生素 D、抗阻与平衡、蛋白质给法）
3. **脑本与感官本**（耳—痴呆的因果链、眼—还敢不敢出门、牙—咀嚼连着营养与社交、脚—剪不了脚趾甲的时候）
4. **钱本与人情本**（养老金三支柱、个人养老金、长护险；家庭、老友、社区、家庭医生签约——老了最先耗尽的其实是社会关系）

### 篇二 · 黑框警告：这三件事先看〔格二〕
> 扉页句：身体从不突然垮掉，它先给你一堆被忽略的提示。

5. **警告一：跌倒是晚年的第一道分水岭**（换鞋凳／卫生间清单／家里十八处陷阱／鞋子怎么挑／力量·平衡·步态三种训练／起坐测试／摔之前身体给过的提醒／**哪些药会让你摔**／摔了之后扶不扶／一次说清的防跌倒就诊清单）
6. **警告二：药不是吃得越多越好**（多重用药／**BRAN 四问**／处方瀑布／老人该避开的几类常见药／老年科最常做的动作是减药／能带去就医的用药清单／保健品与药撞车／目标值可以谈）
7. **警告三：吃不下、咽不下、噎住**（海姆立克／喝水会呛不是小事／为什么越老越不爱吃肉／营养不良与肌肉流失的闭环／吞咽困难时的三餐改造）
8. **三条就医红线与"第一小时"怎么办**（胸痛／卒中／意识不清；跌倒后的第一小时；噎食；一页判断表 → 附录 D）

### 篇三 · 难以启齿与日常保养
9. **记不住：从健忘到痴呆之间到底有多远**（忘放钥匙 vs 忘怎么用钥匙／**家人最早发现的三件事往往比量表准**／早发现能换来什么／挂什么科、做哪些检查、花多少钱／别被恐慌营销收割／确诊之后：一份给家属的年历）
10. **尿、便与体面**（盆底肌是一块可以练回来的肌肉／越怕喝水越漏／夜尿三次以上看什么科／卫生间改造／纸尿裤的三件事／便秘不敢说直到堵死；**附一节：性与亲密——被默认消失的需求**）
11. **睡不着、疼、心里没劲、孤独**（失眠不能只靠安眠药／老人嘴里"没事"的那种疼／抑郁不是矫情／孤独是可进行医学干预的危险因素；**老年自杀：以预防为框架，只写识别与求助，不写任何方法，附求助热线**）
12. **每天怎么吃**（蛋白质：老人比年轻人需要更多却吃得更少／盐油酒汤四笔账／牙口不好也能吃的蛋白质清单／控盐不控味／独居厨房协议／饮水）
13. **每天怎么动**（步速——被称作第六生命体征／力量·平衡·有氧的最小有效剂量／起坐测试／卧床三天丢掉的肌肉要练多久才回来／禁忌与边界／太极·广场舞·快走的真实收益）
14. **疫苗、筛查和体检单：只做值得做的**（四支疫苗含价格与证据／值得做的筛查／不必做的／体检报告怎么读／八十岁以后还要不要筛查）

### 篇四 · 把家、钱、人、权限安排好〔格三〕
> 扉页句：这一格最重要的不是"谁来照顾我"，而是"我提前把哪四样安排好了，就不必求人"。

15. **家：要不要改，要不要搬**（适老化改造清单与各地补贴怎么领／电梯·台阶·蹲厕三道最硬的关／三种住法的账／搬家本身就是一次高风险事件／独居协议）
16. **钱从哪来：制度怎么替你付账**（生活费·照护费·突发一笔三种钱／养老金·医保·惠民保·救助各自的边界／**长护险怎么申请、能报多少**／家庭照护的隐形账单／配置顺序／什么时候不要碰大功率投资产品）
17. **人从哪来 + 反向说明书：给照护者的部分**（居家·社区·机构／怎么评估一家机构／护工与陪护的合同与常见纠纷／**照护的第一定律：照护者也是要用的人**／四道坎／基础技术／"该送机构了"的判断标准／兄弟姐妹怎么分摊而不翻脸／喘息服务）
18. **守住钱：防骗与账户安全**（六种针对老人的诈骗剧本，含 AI 换脸与拟声／密码·手机·验证码的家庭协议／大额转账"冷静 24 小时"家规／被骗之后先做什么：止付→留证→报警／钱不要过早、一次性交出去）
19. **权限设置：趁清醒把权限交出去**（三份关键文件：意定监护·生前预嘱·委托书／遗嘱怎么立才不作废／代理人四条标准／家庭索引表／数字遗产与账号处置）

### 篇五 · 最后一程与善后〔格四〕
> 扉页句：医学昌明到今天，我们对死亡与衰老的回避，却和先辈几乎一样。

20. **怎么开口：那些难以启齿的话怎么和家人说**（为什么我们都绕着"老、钱、尿、死"走／不说出口的代价／**五个关键对话与它们的开场白**／"你想怎样死去"该怎么问才不粗暴／家庭会议／分辨"为你好"和"替你决定"）
21. **走下坡之前：把最后的决定写好**（预立医疗照护计划／抢救还是缓和／安宁疗护不等于放弃／**ICU 的一夜具体会发生什么**／在家里离世要提前准备什么／最后清单）
22. **谢幕之后：家属要办的手续**（头二十四小时／人走了之后的钱／销户清单／继承之前先搞清哪些是遗产／之后一年里剩下的手续）

### 结语 · 走得快一点，死得慢一点
今天就能做的三件事（一页，可打印贴冰箱）＋ 失落与继续（丧亲、独居、尊严与意义）

### 附录（很多人只会翻这几页）
- **A 全国制度台账**：医保两档差异／异地就医备案／慢病长处方／长护险／高龄津贴·失能补贴·适老化改造补贴／安宁疗护可及性——按省市列，**标注政策依据 + 核对日期**（周更主要动这里）
- **B 随身健康信息卡**（慢病／过敏／用药／紧急联系人，可裁下塑封）
- **C 症状速查表**：出现这个症状 → 翻到第几节（**按症状组织，不按知识组织**）
- **D 什么时候必须叫 120：一页判断表**
- **E 话术卡：和家人开口的十句话**（可直接照读）
- **F 去哪找人**：社区、民政、残联、工会、社工、安宁疗护机构名录——**留白让读者填本地号码**

## 五、明确不采纳（附理由）

| 不采纳 | 理由 |
|---|---|
| **"报废回收""售后网点""保修期"**这类把人当机器的词 | 物化老人是最容易冒犯读者的一种聪明。说明书隐喻只保留"拆箱／日常使用与保养／故障自检／权限密码"这些不伤人的部分 |
| **"地球 Online 攻略手册""老龄赛段"**游戏化话术 | 目标读者的语感完全不同；对 60–75 岁中国读者是减分项，甚至冒犯 |
| **一次做完 22 章 / 25–30 万字** | 我们的实测产能是子代理单章产出目标的 40%–70%，还要留"统一扩写补齐"一轮。结构定 22 章，**出稿分两轮**：先写别人给不了的（篇二警告 + 篇四安排 + 篇五善后），再写常识部分（篇一 + 篇三） |
| **外部提纲里的具体数字与机构名直接入稿** | 一律当线索。见下节六处待核 |
| **独立成篇的"分龄行动清单"** | 与四格定位重复；收进第 0 章一页 + 附录 H |
| **"温情叙事为主"的通读型写法** | 与"说明书=查阅型"的定位和活书办法体冲突；人味只留在有出处的真实案例框里 |

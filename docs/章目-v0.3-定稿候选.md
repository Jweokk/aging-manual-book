## 一、读者与两条阅读路径

**两类读者不是两种人，是同一个人生命里的两段时间**——45–60 岁的人既在给自己看，也在替父母看。

- **默认人称**：对读者说"你"，正文第一人称是**正在变老的人自己**。
- **每章末尾固定一小节"如果你是在替爸妈看"**，只回答两件事：**这句话怎么跟他说出口** / **他不同意时你还能做什么**。
- **第 0 章给两条路径**：
  - 路径一 · **我用**：我在第几格（四格定位）→ 按症状查（附录 C）→ 按怕的查（附录 D）
  - 路径二 · **替爸妈查**：先翻第 20 章"怎么开口"→ 再按症状/按怕查 → 再看"他不在场时怎么准备"（建档、问医生、找资源）
- **伦理红线**：替爸妈看 **≠** 替爸妈决定。子女路径的落点永远是"创造条件"，不是"替他选"。
- **非对称内容**：只有子女路径需要写"本人不肯承认、也不在场时怎么办"。

## 二、恐惧轴：怎么接进提纲（本轮的设计）

### 2.1 核心判断：恐惧是资源的反面

你说的三簇痛点，与"四样资源"是一一对应的镜像——所以**不新增第五层，直接合并**：

| 你说的痛点 | 他最怕的具体事 | 对应的资源（书的主线词） |
|---|---|---|
| 身体差了 | 摔了再也起不来／失禁出门丢人／忘了自己是谁／夜里一个人出事 | **自理年限** |
| 没钱 | 钱不够用／看不起病／被护工费拖垮／被骗走 | **钱** |
| 和周围环境和人变差 | 一个人在家没人知道／老伴先走／朋友一个个没了／被子女当孩子／被送去机构 | **关系** |
| （上面三簇的共同底色） | 难为情、低三下四、被剥夺决定权 | **体面** |

**所以四样资源定稿为：自理 / 钱 / 关系 / 体面。**"家人的时间与精力"并入"关系"（照护者损耗本来就是关系的一部分），"体面"是前三簇共同的底色——这比原来"自理/体面/钱/家人精力"更贴你说的痛点，也更好记。

### 2.2 四个装置，把"怕"显式写出来

**装置 ① 序之后单独一节"变老最怕的那几件事，以及这本书怎么接"。**
不渲染、不铺垫，直接点名，每条三栏写清：

| 怕什么 | 怕得对不对 | 翻到哪 |
|---|---|---|
| 摔一跤之后就完了 | 有道理——跌倒确实是分水岭，但**可防**，且改造只要几百块 | 第 5 章 |
| 尿裤子被人发现 | 有道理但不该忍——**大多数能改善**，忍着才是真丢人 | 第 10 章 |
| 忘事就是要痴呆了 | **怕错了方向**——正常遗忘与病理之间隔着很宽一段 | 第 9 章 |
| 老了就是花钱受罪 | **怕错了方向**——花钱的地方有优先级，先花几百块的，别先花几万块的 | 第 12、16 章 |
| 一定被子女送去养老院 | 多半不会——**但你不说，子女就替你决定** | 第 20 章 |
| 拖累子女 | 有道理——所以这本书有一半篇幅在讲**怎么让自己不必被照顾** | 全篇四 |

**三栏的第三栏必须包含三类**，否则就是贩卖焦虑：
1. **怕得有道理的**（承认，给办法）
2. **怕错了方向的 / 怕得不够的**（如"这是老了，正常"——最危险的一句话，其实是该治的）
3. **被商家利用的怕**（焦虑生意：高价体检套餐、脑补品、"一滴血"、以房养老）→ 与第 1 章"焦虑生意"互扣

**装置 ② 章首第二句换成能同时承载"格"和"怕"的固定句式。**
> 走到这一步的人，最怕的是 ___。所以这一章给你 N 个办法，专门对着这个怕。

一句话同时完成"读者定位"和"恐惧点名"，不新增层。

**装置 ③ 每个办法的资源栏改成"换回什么 / 解除哪种怕"。**
> 买回：自理年限｜解除的怕：摔了之后再也起不来

**装置 ④ 附录 D：怕什么 → 翻哪一节（恐惧速查表）**，与附录 C（症状速查表）并列。
两张表按**读者的两种入口**组织：**身体在报警** vs **心里在怕**。这是本书最像"说明书"、也最难被抄走的两页。

**装置 ⑤ 结语的诚实收口**（必须有，否则前面点名恐惧就成了恐吓）：
大部分怕**能减轻**，少数**不能取消**（失能、丧偶、死亡）。这本书的目标不是消灭这些，而是把"不能取消的"变成**可预期、可安排、不措手不及**。

### 2.3 一个必须写进序的观察

你说的三簇怕里，**两簇（钱、关系和环境）不是医学问题**。所以这本书有大约三分之二的内容，在英国那本老年病医生写的书的射程之外——**这才是"本土化"的实质，不是把例子换成中国人名。**

## 三、体例（定稿）

每个办法五栏 + 一行资源：

```
### 起夜那三十秒，是很多老人一生里最危险的时候

- **要花多少**：一根感应夜灯 30–80 元（钱：低｜时间：一次｜体力：低｜面子：零）
- **简单说**：半夜从床上到马桶这段路，眼睛还没适应黑，腿也刚醒……（≤3 句，不许出现没解释的名词）
- 怎么做：① 床到马桶整条路装感应灯；② 走廊清空、地毯贴死；③ 床头放尿壶
- **来源**：B（指南通行建议 + 跌倒地点分布数据，缺单项随机试验）**争议**：夜灯单独降低跌倒率无硬证据，它通常作为改造组合起效
- 特别提醒：**对谁成立**——60 岁健康人／75 岁共病／轮椅使用者，方案不同，见 __
- 换回什么 / 解除哪种怕：自理年限｜摔了之后再也起不来
- **在中国怎么落地**：改造补贴见附录 A；自己找人做要问哪三句话见 __
```

**分档（本书版本）**：官方口径 ／ 第三方研究 ／ 厂商或机构宣称 ／ **本书核对**（我们逐条回源、标核对日期）／ 未标。
> 与另几本活书不同：**本书没有"本书实测"档**（我们不做自测），原"本书实测"位置改为"本书核对"。"未标"计数必须为 0。

**四条写作纪律**：① 标题是动作或判断句，不用"关爱/呵护/温馨/夕阳红"；② 不写"定期体检/适量运动"这类没法执行的废话——要么给频次时长强度，要么不写；③ 涉钱写人民币数字，涉政策写"怎么办 + 去哪问 + 以当地最新口径为准"；④ 人称统一用"你"，**禁止"老年人应……"这种第三人称祈使句**（机械感的真正来源）。

**一条反机械的纪律（新增）**：每章允许有一句**不带形容词的承认**——不做安慰、不评价，只把事实说出来。人味靠"承认"，不靠煽情。

**案例三档 + 一条禁例**：有出处可署名（公开报道/官方文件/我们访谈）→ 可当案例；无出处的转述 → 标"侧写"、不得当证据；编的 → 不允许。**禁例：不许写"隔壁老王"式合成人物当案例。**

**合规三条**：
1. **非处方声明**：只写"去找谁、问什么"，不写剂量、不写处方、不做诊断。
2. **推荐类内容必须声明利益关系**（养老机构、辅具、保险）。
3. **老年自杀那章**：只写识别与求助、附求助热线，**任何方法细节一律不写**。

## 四、骨架

### 第 0 章 这份说明书怎么用
- 这本书是谁写的（**整理者**，方法=公开文献+官方文件+采访，**没有自测**）
- 四样资源：自理 / 钱 / 关系 / 体面——**各算各的，不互相折算**（"少摔一跤"和"每月省 300 元"不在同一把尺子上）
- 两条路径：我用 / 替爸妈查
- 每条怎么看：五栏分别回答什么
- **如果你只有十分钟：现在就做的三件事**
- 什么时候这本书不适用：急症、已明确诊断、急诊——先看医生

### 序 · 老年人就是我们未来的样子
＋ **变老最怕的那几件事，以及这本书怎么接**（装置 ①，含"怕错了方向"与"被商家利用的怕"）

### 篇一 · 存本钱：还没老的时候〔阶段一〕
> 决定你 80 岁摔不摔得断髋骨的那几步，是你 14 岁在操场上跑的。

1. **变老不是某一天发生的**（四个型号：衰弱/肌少症/共病/失能；发病率压缩；五个误会，"这是老了，正常"最危险；**焦虑生意**）
2. **骨本与肌肉本**（受：怕不能自理）
3. **脑本与感官本**（耳—痴呆的因果链、眼、牙、脚）
4. **钱本与关系本**（养老金三支柱/个人养老金/长护险；家庭、老友、社区、家庭医生签约——老了最先耗尽的其实是关系）

### 篇二 · 黑框警告：这三件事先看〔阶段二〕
> 身体从不突然垮掉，它先给你一堆被忽略的提示。

5. **警告一：跌倒是晚年的第一道分水岭**（怕：摔了再起不来）——换鞋凳/卫生间清单/家里十八处陷阱/鞋子/力量·平衡·步态/起坐测试/**哪些药会让你摔**/摔了之后扶不扶/防跌倒就诊清单
6. **警告二：药不是吃得越多越好**（怕：吃出问题、被药物套住）——多重用药/BRAN 四问/处方瀑布/该避开的几类常见药/减药/用药清单/保健品撞车/目标值可以谈
7. **警告三：吃不下、咽不下、噎住**（怕：噎死、饿死）——海姆立克/喝水会呛/越老越不爱吃肉/营养不良与肌肉流失的闭环/三餐改造
8. **三条就医红线与"第一小时"**（怕：来不及）——胸痛/卒中/意识不清；跌倒后第一小时；噎食 → 附录 E 一页判断表

### 篇三 · 难以启齿与日常保养
9. **记不住：从健忘到痴呆有多远**（怕：变成别人的负担）
10. **尿、便与体面**（怕：丢人）＋ 一节：性与亲密——被默认消失的需求
11. **睡不着、疼、心里没劲、孤独**（怕：一个人扛不住）——含**老年自杀**：只写识别与求助、附热线
12. **每天怎么吃**（怕：吃不下、吃不对）
13. **每天怎么动**（怕：动不了）
14. **疫苗、筛查和体检单：只做值得做的**（怕：白花钱、被过度医疗）

### 篇四 · 把家、钱、人、权限安排好〔阶段三〕
> 这一阶段最重要的不是"谁来照顾我"，而是"我提前把哪四样安排好了，就不必求人"。

15. **家：要不要改，要不要搬**（怕：环境不安全、被搬走）
16. **钱从哪来：制度怎么替你付账**（怕：没钱、怕拖累子女）——三种钱/养老金·医保·惠民保·救助的边界/长护险/家庭照护的隐形账单/配置顺序/什么时候别碰高风险产品
17. **人从哪来 ＋ 反向说明书：给照护者的部分**（怕：没人照顾、怕拖垮子女）——含"照护的第一定律：照护者也是要用的人"、四道坎、"该送机构了"的判断标准、兄弟姐妹怎么分摊、喘息服务
18. **守住钱：防骗与账户安全**（怕：被骗、老了被占便宜）——六种诈骗剧本含 AI 换脸拟声/验证码家庭协议/大额转账冷静 24 小时/被骗后止付→留证→报警
19. **权限设置：趁清醒把权限交出去**（怕：失控、被夺权）——意定监护·生前预嘱·委托书/遗嘱怎么立才不作废/代理人四条标准/家庭索引表/数字遗产

### 篇五 · 最后一程与善后〔阶段四〕
> 医学昌明到今天，我们对死亡与衰老的回避，却和先辈几乎一样。

20. **怎么开口：那些难以启齿的话怎么和家人说**（怕：说不出口、家里人不敢谈）
21. **走下坡之前：把最后的决定写好**（怕：疼着死、死得没尊严）——ACP/抢救还是缓和/安宁疗护≠放弃/**ICU 的一夜具体会发生什么**/在家离世要准备什么/最后清单
22. **谢幕之后：家属要办的手续**（怕：给家人留一堆烂摊子）——头 24 小时/人走了之后的钱/销户清单/继承前先分清哪些是遗产/之后一年的手续

### 结语 · 走得快一点，死得慢一点
今天就能做的三件事（一页，可打印贴冰箱）＋ 失落与继续 ＋ **诚实收口（装置 ⑤）**

### 附录
- **A 全国通用制度台账**（国家层面口径：医保两档/异地就医备案/慢病长处方/长护险制度框架/高龄津贴·失能补贴·适老化改造补贴/安宁疗护）——**每项标政策依据 + 核对日期**

## 五、英文版方案（本轮新定）

**核心问题**：这本书的价值有一大半在中国制度上，原样翻译出去，英文读者会看不懂、也用不上。所以不照译。

**分工三块**：

| 内容 | 英文版怎么处理 |
|---|---|
| **医学与照护（篇一、篇二、篇三）** | 直接译。**选源优先国际循证**：WHO、Cochrane、NICE、美国老年医学会（AGS）、日本介护经验 |
| **制度与钱（篇四、附录 A、部分附录 G）** | **改写成"中国大陆养老制度说明 + 与英文读者所在制度的差异提示"**，不直译医保名词 |
| **沟通与家庭文化（第 20 章、子女路径小节）** | 中国本土材料优先——这块国外没有对应物，是我们的独有内容 |

**选源规则（写进体例，中英同用）**：
- 医学 / 照护 / 老年综合征 → **国际循证指南与系统综述优先**（A 档证据大多落在这里）
- 制度 / 政策 / 待遇 → **中国官方文件唯一**（卫健委、医保局、老龄事业发展公报）
- 文化 / 沟通 / 家庭 → **中国本土材料优先**
- **日本经验单列**：介护保险、地域包括照护体系——同属东亚、老龄化最前沿、文化接近，是国际经验里最可迁移的一支

**实现**：沿用既有机制（`book-en/`），但英文版入口文案要写清"本书针对中国大陆制度，通用部分对各国读者有用"。

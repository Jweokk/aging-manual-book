# 16-第16章-钱从哪来制度怎么替你付账.md 剩余待核

- 门诊慢特病：能跨省直接结算的是全国统一的 10 个病种，但"待遇"病种名单和报销比例由各统筹地区自己定，本章写不出一个通用比例，只能写"怎么申请、去哪儿问"。
- 异地就医备案的材料、时限、报销降幅各地不一致，本章的降幅区间是概括，没有逐地回源，以参保地为准。
- 惠民保的赔付率、参保率这类数没有全国统一官方发布（"赔付率超 90%"出自媒体转引地方监管人员，"总参保率约 5%"出自业内研究文章），用的时候以本地产品条款和官方通报为准。
- 长护险各地待遇差别大，本章写的是国家层面的时间线和目标，具体到哪个城市能报多少、怎么评估，要回本地医保局问。
- 家庭照护的误工损失和护工价格，没有全国统一统计，本章只写了要算哪几笔账。

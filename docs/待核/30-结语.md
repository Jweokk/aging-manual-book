# 30-结语.md 剩余待核

不想做，有些决定还想再放一放，都是正常的。它只是把选项摆在这里，什么时候拿起来，你自己定。如果你是在替爸妈看这本书，请把"替"字看重一点：你可以替他们查、替他们问、替他们把话头递过去，但最后那个决定，还是他们的。 再说一句这本书的来路。它不装医生，也不假装自己是老人。它是把公开的指南、官方文件、能查到出处的报道，一类一类整理成你现在能用的样子。每章末尾都列了出来；没核到原文的地方，都老老实实标了〔待核〕，没有含糊过去。遇到"这本书说"和"医生说的"不一样的时候，请以见过你本人的医生为准。 说明书是用旧的，日子得自己过。这本书能做的，只是让你翻开它的时候，少一点独自硬扛的感觉。 剩下的，慢慢来。

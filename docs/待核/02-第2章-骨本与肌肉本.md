# 02-第2章-骨本与肌肉本.md 剩余待核

- **跳类、冲击性动作对中老年人骨密度的具体效果，没有核到中国本土的量化研究。** 方向有（负重、冲击能刺激骨），但"跳多少、跳多久能让骨头更硬"缺中国人群的剂量数据，本章按"方向有、剂量不明"处理。下一步：查《原发性骨质疏松症与肌少症的营养和运动管理专家共识（2025年）》及后续中国人群运动干预研究。
- **社区能不能做骨密度筛查、能不能转 DXA、免费体检含不含骨密度，各地不同。** 骨密度不在国家基本公共卫生服务"老年人健康管理"的标准体检项目里；社区能否加做超声、前臂 DXA、定量 CT 筛查、能否转诊 DXA，由地方安排（中国疾控中心慢病中心 2025 提到社区可先做超声等筛查）。下一步：逐省核对当地卫健委的免费体检项目和转诊路径。

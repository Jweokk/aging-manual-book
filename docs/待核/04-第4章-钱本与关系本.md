# 04-第4章-钱本与关系本.md 剩余待核

- "全国基本养老保险参保 10.76 亿人"已回到人社部原始发布（《2025 年度人力资源和社会保障事业发展统计公报》与人社部 2026-01-27 例行新闻发布会），不再用二手评论。"个人养老金开户超 1.5 亿"没能落定到人社部的原始口径，只有《2025 年度国家老龄事业发展公报》里的"累计缴存金额 1452 亿元"是官方的；开户数取自多家财经媒体对人社部的转引（约 1.5 亿，2025 年），用的时候以最新官方口径为准。
- 长护险的覆盖数随时间往前推、口径也不完全一致：国家医保局 2025-09-25 说覆盖 1.9 亿人、累计支出超 850 亿元；新华社与老龄事业公报到 2025 年底的口径已是约 3 亿人。本章用后者。各地实施时间和待遇差别大，以参保地医保局口径为准。
- 孤独与死亡风险的关联有队列研究支持，但"从现在开始维持关系能不能延寿"，缺针对中国老年人的干预研究。

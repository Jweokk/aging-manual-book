# 《变老说明书》体例规范 v0.1（写作风格）

- 状态：**风格定稿候选**（与章目 v0.4 配套；本文件用于写样板章，以及后续 brief 子代理时的"语气样板"依据）
- 日期：2026-10-09

---

## 一、一句话风格

> **说明书的写法，人话的句子，可以查的出处。**
> 硬，只硬在**证据和步骤**上；不硬在**术语和语气**上。

展开六条：

1. **说明书体**——正文不煽情、不抒情、不给人生建议；只回答"做什么、怎么做、花多少、来源、对谁成立"。
2. **人味只放两处**：① 每章的**一句承认**；② **有出处的真实案例框**。别处不许抒情。
3. **可以查**——每条关键数字有出处、有分档；政策内容给"怎么办 + 去哪问"，并说明以当地最新口径为准。
4. **能执行**——不写"定期体检""适量运动"这类没动作的句子；要么给频次、时长、强度，要么不写。
5. **能查得到**——骨架按时间线四格，装置按说明书的栏目化：症状速查表、恐惧速查表、120 判断表、话术卡。
6. **不折算**——四样资源（自理/钱/关系/体面）各算各的；"少摔一跤"和"每月省 300 元"不在同一把尺子上。

## 二、外部三类风格的取舍

| 外部提议 | 我们的取舍 |
|---|---|
| **科普实用型**（像《变老之前要知道》：专业但好读） | **取一半**：好读要，专业不摆在前台。原书是医生写的临床视角，偏医学；本书有三分之二是钱、关系、制度、善后，医学只占一部分 |
| **硬核干货型**（像 GitHub《高性价比人生指南》：数据驱动、结构极简） | **取四件套，不取它的纯条目**：取"成本 / 收益 / 证据等级 / 原始出处"→ 变成我们的五栏；**不取"只引期刊论文"**（制度内容期刊里没有，必须引官方文件）、**不取"纯条目无过渡"**（它不做叙事所以能纯条目；我们 22 章的条目必须有主线牵着，否则就是罗列） |
| **人文叙事型**（故事引出问题，再给方法） | **不取叙事，取它的"场景开场"**：章首用一个具体场景起手（如"半夜三点，从马桶上站起来，眼前一黑"），然后立刻切回说明书体。叙事会稀释可查性，我们不写"故事线" |
| **游戏化话术**（"地球 Online""老龄赛段""攻略手册"） | **不取**：与 60–75 岁中国读者的语感不合，容易冒犯 |
| **物化比喻**（"保修期""报废回收""售后网点"） | **不取**：把人比作机器。只保留不伤人的那几个说明书动作（拆箱、日常维护、故障自检、权限设置） |

> 结论：我们走的是**第四种**——**说明书体 + 实证**。既不是"好读的科普"，也不是"冷冰冰的硬核"，而是"**语气平实、字字可查、每一条都能今天就做**"。

## 三、人称与姿态（最容易翻车的地方）

- **对读者说"你"**。禁止"老年人应……""建议老年人……"这种第三人称祈使句——**把读者推到对面去，就是机械感的真正来源。**
- **自我指称尽量不出现**。作者是整理者：能写"通行做法是……""指南里写……""一条能查到的做法是……"，**不写"我们认为""我们建议"**。说明书不该有主张者的口吻；有争议就摆出两边证据。
- 涉及子女视角时人称切换为"**如果你是在替父母看**"，且**只写"怎么说出口"和"他不同意时你能做什么"**，不写"替他决定"。
- **不许用"老人"以外的轻慢称呼**（如"老头老太太""银发族"）；正文用"你"，叙述他人时用"老人""高龄者""失能者"，需要精确时用年龄段。

## 四、条目的结构

**标准五栏 + 两行**（五栏是**上限，不是配额**；纯事实类条目可以只写三栏）：

```
### 站着穿鞋，比坐着穿鞋更容易摔

- 要花多少：200–400 元，一次搞定（钱：低｜时间：一次｜体力：低｜面子：零）
- 简单说：卫生间和玄关是老年家里摔倒最多的两个地方。很多人只装了个灯泡，没装灯。
- 怎么做：① 换鞋凳要有靠背、不带轮；② 旁边墙上装一根竖向扶手；③ 鞋架抬到不用弯腰的高度
- 来源：B｜通行建议，有跌倒地点分布数据，但没有单项随机试验
- 特别提醒：**对谁成立**——轮椅使用者要的是另一套高度，见 __
- 换回什么 / 解除哪种怕：自理年限｜摔了之后再也起不来
- 在中国怎么落地：改造补贴见附录 A；自己找人做要问哪三句话，见 __
```

**"轻条目"（允许并鼓励）**：只写"要花多少 + 怎么做 + 来源"，例如"把地垫全撤了"这种一句话能说清的事，不必凑五栏。**凑栏位就是形式主义**。

## 五、标题的三种句式（+ 反例）

标题必须是**动作**或**判断**，不许是**话题**：

- **动作式**：把鞋架抬到不用弯腰的高度／撤掉卫生间那条地垫
- **判断式**：站着穿鞋比坐着穿鞋更容易摔／尿失禁大多数能改善，忍着才是真丢人
- **警告式**：摔之前，身体给过三次提醒／噎住的那一分钟，决定生死

❌ 反例（一律改掉）：居家环境改造建议 ｜ 关于用药的注意事项 ｜ 老年心理健康问题探讨 ｜ 关爱老人从细节做起

**章名可以有情绪，节名要朴素**（如第 5 章"警告一：跌倒是晚年的第一道分水岭"是章名，其下的节名保持朴素），这样情绪只出现在读者需要被叫醒的那一次。

## 六、证据的分档与写法

分档：**官方口径 / 第三方研究 / 厂商或机构宣称 / 本书核对 / 未标**（本书无自测，"未标"计数必须为 0）。

写法三条：

1. **只在关键数字上用字母**，并跟**一句人话理由**："B｜通行建议，有跌倒地点分布数据，但没有单项随机试验"。不要写成学术引用体。
2. **争议不用"争议："这个标签**，用"**但是**"起句，更像人说话："但是——夜灯单独降低跌倒率没有硬证据，它通常作为整组改造的一部分起效。"
3. **"本书核对"要写清核对日期**：政策类条目写"（2026-10 核对）"。政策数字天生会变，这是本书最需要季度校准的部分。

**"以当地最新口径为准"只在制度类条目出现**，并用统一角标，不要每条重复（否则会变成口头禅）。

---

## 七、案例与"没有案例时怎么办"

三档入库：① **可署名、可给出处**（公开报道 / 官方文件 / 我们访谈）→ 可当案例进正文；② 无出处的转述 → 只能标"侧写"，**不得当证据**；③ 编的 → 不允许。
**禁例**：不许写"隔壁老王""我的一位患者"这类**合成人物**——这是外部 AI 稿最常见的做法，最容易被读者识破。

**（待你拍）没有真实案例时用什么替代**，三个选项：
- **A** 用公开报道的具名案例（数量有限，但最硬）
- **B** 用明确标注的"**侧写**"（虚构场景，正文里标出来，读者知道它不是事实）
- **C** 干脆不要场景，章首只给"这一章解决什么问题"

我的建议：**A 优先，A 不够时用 C 兜底，B 只在极少数必要处使用且必须标注。**

## 八、四条纪律 + 承认句 + 禁用词

**四条纪律**：① 标题是动作或判断（见第五节）；② 不写没有动作的句子（"定期体检""适量运动""保持乐观"）；③ 涉钱写人民币数字，涉政策写"怎么办 + 去哪问"；④ 人称统一"你"，禁第三人称祈使句。

**承认句（每章一句，位置自定）**：不带形容词，不做安慰，不评价，只把事实说出来。
> 例："这不是你想看到的，但它是真的。""没有人能把这件事变得不难受。"

**禁用词表**：关爱、呵护、温馨、夕阳红、银发族、"老年人应"、游戏化词（攻略/赛段/Online）、物化词（报废/保修期/售后）。**"高性价比"这四个字不进正文**（见下节）。

---

## 九、"高性价比"要不要出现在正文

**建议：不进正文。** 理由三条：

1. 一出现就带**算计感**，和这本书"体面"这一资源的调性打架；
2. 它会诱导读者**把四样资源折算**——而那正是我们明令禁止的；
3. 它的位置应该在**序**：用一段说清"这本书记四笔账，各算各的"，然后全书不再出现。

参考书那本可以满篇"性价比"，因为它只算一笔账（寿命与钱）。我们算四笔，不能用一个词盖住。

---

## 十、为"65 岁的人一次读得完"服务的约定

- **一条不超过一屏**：五栏全满时控制在 300–400 字。
- **每页条目数克制**：宁可一页两条写透，不要一页六条写浅。
- **正文里不出现需要读者自己换算的东西**：给"一次 200–400 元"而不是"约占月收入的 X%"。
- **每章结尾给一句"如果你今天只能做一件事"**（把章内最重要的一条拎出来）。
- 章节编号、速查表、术语保持一致，**同一件事在全书只有一个名字**（比如统一说"失能评估"，不要一会儿"评定"一会儿"认定"）。

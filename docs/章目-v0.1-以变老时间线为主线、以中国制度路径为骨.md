## 一、主线（打掉"罗列感"的那个东西）

**一句话主线：**

> 变老不是突然发生的，它是个悄无声息的过程——**这本书只回答三件事：你现在站在变老的哪一阶段？这一阶段该做什么？这些事在中国，找谁、花多少钱、值不值？**

**为什么这是主线而不是罗列。** 老年话题最容易被写成"跌倒、失禁、用药、痴呆、临终"的并列清单，读者读完不知道自己该从哪儿下手。本书把主题**挂到一条时间线上**，读者先自我定位（我现在在第几格），再只读自己那一格——这正是"说明书"该有的用法（**查阅型，不是通读型**）。

**四格坐标（读者自我定位装置）：**

| 阶段 | 读者现在的状态 | 该做的事 | 对应篇 |
|---|---|---|---|
| 阶段一 | 还没老（30–50 岁，或自认还年轻） | 存本钱：骨、肌、脑、钱、人情 | 篇一 |
| 阶段二 | 刚变老（50–65 岁，身体开始给信号） | 读信号、该查的查、该改的改 | 篇二 |
| 阶段三 | 开始要人帮（体力不支 / 家里有失能老人） | 家、钱、人，三样提前安排 | 篇三 |
| 阶段四 | 最后一段（高龄 / 重病 / 临终） | 怎么谈、怎么安排、怎么不遗憾 | 篇四 |

**主线可见性规则**（解药，四处重复）：① 序的第一句；② 每篇扉页一句过渡；③ **每章开场第二句用固定句式**——"走到这一步的人，通常在纠结 ___。所以这一章给你 N 个办法：___。"；④ 结语回扣。读者读三章就形成肌肉记忆。

**序末放"读者定位表"**：把自己的情况对号入座——"你担心的是自己的老，还是父母的老？"（两者关注点完全不同，本书在每章末尾用一行小字分列）。

## 二、体例提案（办法体 + 说明书的"性价比"标注）

沿用活书既定**办法体**（每章 2–3 句说清解决什么问题 + 5–12 个办法，每办法「做什么／怎么做／例子／别踩的坑」，3,000–5,000 汉字）。

**本书新增一处**（来自 GitHub 那份指南的启发，且正好是"说明书"该有的样子）——每个办法后跟一行**四格标注**：

> `花多少｜值不值｜证据够不够｜出处`

- **花多少**：钱 + 时间 + 体力（老人最缺的是体力，不是钱）
- **值不值**：收益与代价的直白比较（例如"做完这一步，能少住一次院吗"）
- **证据够不够**：分档 【官方口径】／【第三方研究】／【厂商或机构宣称】／【本书实测或采访】／【经验之谈】
  - 沿用既有活书的分档表，**不新造标签**；且"未标"计数必须为 0
- **出处**：每条给可点的原始来源；核不到原文就写 `〔待核 N〕`，章末集中列"本章我不确定的地方"，**严禁编数**

**并且每个办法后面必须挂一行"在中国怎么落地"**——这就是本书与英文原著的根本区别，也是它的全部价值所在（见下节）。

**章末两节固定**：`本章说明与存疑` + `本章数据来源`。正文不加上标（沿用两层制：数字句末就地分档 + 章末来源 + 全书附录台账）。

## 三、本地化：本书的骨头（这是提纲的重点）

英译本给的是**通用医学与照护常识**；中国读者真正卡住的地方是**制度路径、地域差异和开口方式**。所以本地化不是"把例子换成中国人名"，而是**每个办法都要落到一条可执行的中国路径上**。分六类，逐章贯穿：

### 1. 制度路径（最硬、最不可替代）
- **医保**：职工医保 / 居民医保两条线的待遇差；门诊慢特病（高血压、糖尿病等的认定与报销）；异地就医备案（子女在异地工作、老人随迁或反向就医）；大病保险与医疗救助二次报销
- **长期护理保险**：试点城市的参保与失能评估、待遇形式（服务/现金）、与医保的边界
- **养老与照护**：居家社区机构相协调、医养结合；公办养老机构轮候、普惠养老、护理型床位；家庭养老床位
- **补贴与改造**：居家适老化改造补贴、康复辅具（轮椅、护理床、助听器）的补贴或租赁、残疾人证与护理补贴
- **安宁疗护**：试点推进情况与本地可获得性（这一条很多家属根本不知道该问）
- **评估工具**：ADL / Barthel 指数、失能等级评估——办许多待遇都要先过这一关，很多家庭卡在不会申报

> 每一条都要在附录 A 落成**可查的台账**（按省/市列，标注政策依据与更新日期），周更时只动台账。

### 2. 地理差异（南北方、城乡，用户原话点名的部分）
- **南北**：日照与维生素 D／骨密度、冬季采暖与呼吸道疾病、冰雪路面跌倒、饮食咸淡与血压、潮湿与关节
- **城乡**：农村留守老人、村医与乡镇卫生院、子女进城后的空心家庭；城市独居与电梯楼里的"看不见的失能"
- **气候与季节**：冬季是跌倒与心脑血管事件的高峰——章节排布要跟着季节提醒走（周更可以做成"本月该注意什么"）

### 3. 家庭结构
独生子女赡养、异地子女的**远程照护**（装摄像头/呼叫器、委托邻居、远程缴费与挂号）、隔代抚养对老年体力的透支

### 4. 文化心理（决定"能不能开口"，是本书立命的地方）
避谈死亡、家丑不外扬（失禁/痴呆被藏起来）、"送养老院=不孝"的内疚、老人对"麻烦子女"的恐惧、中医与康复的信任结构

### 5. 法律（中国特有、且与"告别期"强相关）
《民法典》遗嘱与公证、**意定监护**、居住权（新增制度，养老房产可落）、深圳对**生前预嘱**的立法实践（全国尚无统一立法——须如实写明这一边界）

### 6. 数据与权威源
国家卫健委、国家统计局、《老龄事业发展公报》、地方卫健委与医保局；**境外经验只能当线索，制度数字必须有中国官方出处**

## 四、章目（序 + 4 篇 + 17 章 + 结语 + 附录）

（每章后面方括号是**本地化重头戏**）

### 序 · 老年人就是我们未来的样子
把自己当成预备老年人；长寿 ≠ 幸福，有质量的长寿才是福分；发病率压缩（Compressed Morbidity）。**序末：四格定位表 + 给子女的一页。**

### 篇一 · 还没老：现在就该存的本钱〔阶段一〕
> 扉页句：变老这件事，最早的准备发生得比你以为的早得多——你 14 岁在操场上跑的那几步，决定了 80 岁摔不摔得断髋骨。

1. **变老已经在进行**：为什么人觉得自己"一下子老了"；什么时候开始准备不算早
2. **骨本与肌肉本**：骨密度、日照与维生素 D、抗阻与平衡训练 [北方日照、冬季、城乡体力活动差异]
3. **脑本、耳本、牙本**：听力下降与痴呆风险、视力、口腔与营养 [助听器补贴、口腔医保]
4. **钱本**：养老金三支柱、个人养老金、长期护理保险、房产与反向抵押/居住权的可能 [制度路径最重的一章]
5. **人情本**：家庭、老友、社区、家庭医生签约——老了最先耗尽的其实是社会关系

### 篇二 · 刚变老：读信号，该查的查〔阶段二〕
> 扉页句：身体从不突然垮掉，它先给你一堆被忽略的提示。

6. **读身体的信号**：走得慢、起身难、夜尿、忘事、听不清；家庭自测量表怎么用 [社区免费体检、家庭医生]
7. **跌倒：最贵的一次意外**：为什么骨折之后一年是道坎 [居家适老化改造补贴、防滑与照明、助行器、北方冰雪]
8. **尿失禁：一个必须开口的尴尬**：盆底康复、护理用品、耗材开销 [如何开口的第一套话术；医保与耗材]
9. **吃药这件事**：多重用药、处方精简、中西药相互作用、家庭药箱 [社区药师、慢病长处方政策]
10. **忘了：从健忘到痴呆**：正常老化 vs 病理；筛查与认知门诊 [走失预防、照护者支持、残疾人证]

### 篇三 · 开始要人帮：把家、钱、人安排好〔阶段三〕
> 扉页句：这一阶段最重要的不是"谁来照顾我"，而是"我提前把哪三样安排好了，就不必求人"。

11. **家怎么改**：适老化改造、扶手/坡道/呼叫器/防滑地面 [改造补贴怎么申领；南北气候差异]
12. **钱从哪来**：医保三档路径、门诊慢特病、异地就医备案、长护险、补贴与商保 [**本地化密度最高的一章**]
13. **人从哪来**：居家照护、社区居家养老服务、护工与保姆、家庭医生与分级转诊 [选养老机构与护工的核验清单]
14. **照护者**：别把自己累垮：喘息服务、照护技能、兄弟姐妹之间怎么分工 [独生子女与异地子女的远程照护]

### 篇四 · 最后一程：怎么谈、怎么安排〔阶段四〕
> 扉页句：医学昌明到今天，我们对死亡与衰老的回避，却和先辈几乎一样。

15. **我们该如何谈论它们**：三句关键问题怎么问、什么时候问、说不出口时怎么办 [全书的题眼："你想怎样度过最后一段"——不用直白粗暴的方式]
16. **临终**：安宁疗护能做什么、生前预嘱与意定监护、遗嘱与公证、身后事 [深圳立法实践与全国立法边界]
17. **失落与继续**：丧亲、独居、尊严与意义——变老不是人生的退场，而是另一段需要认真经营的时光

### 结语 · 走得快一点，死得慢一点
今天就能做的三件事（可打印一页，贴在冰箱上）。

## 五、与两本参考书的关系（避免重复与侵权）

- **不是《变老之前要知道》的中译本或缩写**。取其**姿态**（如何谈论、把自己当预备老年人、发病率压缩），不取其文本；引用只做短引 + 转述 + 标明出处（《著作权法》24 条适当引用）。
- **与 GitHub 那份指南的分工**：它按**主题**横向罗列（长寿防病/理财/法律/婚育…），本书按**变老时间线**纵向走，且只做"变老"这一段。可借鉴其体例（成本/收益/证据等级/出处），**不许沿用它的数字**——其创建一个月即 56k 星，内容标注"只引期刊论文"，但引用本身未经核验，一律当线索。

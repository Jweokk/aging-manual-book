## 三、写的时候改掉的两处清单说法（清单原话有误）

1. **「华法林与西柚」不准确。** 西柚的主要相互作用对象是他汀（辛伐他汀、洛伐他汀、阿托伐他汀）、硝苯地平这类降压药，以及利伐沙班、阿哌沙班这类新型抗凝药。华法林要盯的是维生素 K（深绿叶菜吃法要稳定）、酒精、银杏当归。6.11 按这个写了。
2. **「青光眼急性发作别当胃病」原书已覆盖。** 3.8 已写"眼睛突然剧痛发红 + 视力下降 + 恶心呕吐"当天就医，只是没点"青光眼"这个名。3.10 因此只补慢性的、不红不疼那一型，外加筛查。

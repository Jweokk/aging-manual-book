# 引用与版权规范 v1（《变老说明书》）

- 日期：2026-10-09
- 适用范围：本书所有正文、附录、序、站点与 PDF
- 与《体例规范 v0.2》的关系：体例规范管"怎么写得好"，本规范管"怎么写得不侵权、引得住"

---

## 一、三条红线

1. **禁逐字搬运。** 与任何来源连续重合 **≥12 个汉字**即视为搬运（专有名词、法条原文、指南名称除外），必须改写为自己的话。
2. **二手来源必须标"转引"。** 我们没读到原始文献时，一律写"转述"或"转引自 <我们实际读到的来源>"。**禁止把二手来源写成"引自原书"。**
   > 本书最大的一个坑：《变老之前要知道》我们**没有读过原书**，读到的是一篇书评（2026-10-09 北京晚报关于该书的内容）。全书凡涉及这本书的引述，一律按转引处理。
3. **引文必须加引号 + 注明来源与作者**；引用中译本时**注明译者**。

---

## 二、引文上限（比法律要求更严的自律）

- 单处引文 **≤ 40 字**。
- 同一作者/同一本书，全书引文合计 **≤ 200 字**，并分散在不同章节。
- 引文的用途只能是**介绍、评论、说明问题**，不得替代原作品——不许出现"抄一段就完事"的段落。

---

## 三、每条信息用哪种方式，必须选一种并标清

| 方式 | 用法 | 标记 |
|---|---|---|
| **引文** | 原话本身有分量的句子 | 加引号 + 作者 + 出处（+ 中译本译者 + 页码） |
| **转述** | 默认方式，用自己的话 | 出处；不逐字重合 ≥12 字 |
| **转引** | 我们没读到原文 | "转引自 <实际读到的来源 + 日期>" |
| **事实/数据** | 只用事实，不抄表达 | 一律给分档角标（官方口径／第三方研究／厂商或机构宣称／本书核对） |

## 五、其他来源的规矩

- **法条**：法律条文本身不受版权保护；引用注明法律名称 + 条号（如《民法典》第 33 条）。
- **官方文件**：注明发布机关、文件名、发布日期、链接。
- **医学指南与系统综述**：只引结论，注明指南名 + 年份 + 链接；**不整段翻译**。
- **新闻案例**：只使用公开报道中的**事实**（事实不受版权保护），**不得复制报道的叙述文字**；标明媒体与日期。
- **图片与表格**：一律自绘；不得使用任何未授权图片。如要引用他人图表，必须取得授权，或按自有数据重绘。
- **受访者**：访谈须取得同意，姓名与细节的匿名化按受访者要求处理，正文标注"经本人同意"。

## 八、每章写完必跑的检查（`tools/check_citation.py`）

对每章跑一次，命中项逐条人工判定：

1. 与登记语料（书评、原书摘录、外部提纲、参考书、GitHub 项目）做 **n-gram 重合检测**，阈值 12 字；
2. 引号配对检查 + "有引号但无出处"检查；
3. "转引/转述"标注是否与来源性质相符（凡引二手来源必须出现"转引"字样）；
4. 未标分档的数字（"未标"必须为 0）。

> 这一道加进原有的四道验收（结构 / 违规词 / 数字回源 / 父代理复抓页面）之后，成为**第五道**。

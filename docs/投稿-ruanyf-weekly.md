国内不缺讲变老的书，缺的是“能照着办”的那一本。

- 国外译作讲观念和谈话——《最好的告别》《变老之前要知道》都好，但制度、钱和手续是外国的。
- 官方材料权威又免费——老年健康核心信息、安宁疗护实践指南、老年人膳食指南、生前预嘱模板，可它们散在十几个部门的几十份文件里，一份只管一件事，也没有一份是用读者能用的话写的。
- 国内出的工具书，要么只讲一个专题（合理用药、法律维权、养老钱从哪来），要么偏退休生活的心灵向，要么是给临床和照护者看的专业手册，普通人翻不动。
- 开源里这一类基本是空的——搜 GitHub，找不到一本对口的中文养老手册。

**《变老说明书：你或你父母的下一步》**希望补上这个空：中国本土 + 全周期（还没老 → 出问题 → 安排家钱人 → 最后一程和身后）+ 每条带证据分档和官方入口 + 开源可纠错。22 章 + 6 个附录，免费，持续更新（政策与数字每季度重新回源校准）。不用注册，打开网页就能查，也能下整本 PDF（223 页）。

在线阅读：https://aging.fly2ai.top
开源地址：https://github.com/Jweokk/aging-manual-book （附整书 PDF 下载）

起点很朴素：自己想查这些事，才发现长护险怎么申请在医保局，失能补贴在民政，生前预嘱只有深圳有地方法规，安宁疗护的指南在卫健委，身后手续在公安和银行。借助 AI 做资料搜集和初排，再逐条回源核对，这份资料按“变老分四个阶段”重排了一遍：存本钱（骨、肌肉、脑、钱、关系）→ 跌倒、用药、噎住、就医红线 → 记不住、失禁、疼、孤独、怎么吃怎么动、体检单 → 住哪儿、钱从哪来、照护者、手机与骗局、权限交给谁 → 怎么开口、生前预嘱、身后手续。

每个条目都用同一套栏目写：**要花多少、简单说、可以怎么做、来源、特别提醒、换回来的**。急起来不用读全书——**附录 B 按症状查（疼、漏、忘、摔），附录 C 按心事查（怕变穷、怕拖累子女、怕孤独、怕疼着死），附录 D 是“什么时候必须叫 120”**。

可核对的地方：
- 每个数字按证据分档 A/B/C，二手来源标〔转引〕，核不到出处的明标〔待核〕（现余 14 处，多是“全国无统一口径”的项）。
- 不写剂量、不写处方、不做诊断，只写“去找谁、问哪三句”。

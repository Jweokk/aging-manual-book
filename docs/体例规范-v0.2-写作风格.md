## 一、一句话风格

> **说明书的写法，人话的句子，可以查的出处。**
> 硬，只硬在**证据和步骤**上；不硬在**术语和语气**上。

---

## 二、对"高性价比人生指南"的处置：不学其形，学其精髓

**不进正文、也不模仿其写法。** 要学的是它**对读者的友好性**——把它拆成六条，我们照做：

1. **可查**：每条关键数字都有出处，读者不信可以去点开看。
2. **可执行**：每条都能落到一个今天就能做的动作上，不给"保持健康"这种没法执行的话。
3. **算得清**：花多少钱、花多少时间、值不值，写明白（我们进一步把"面子"也算进去）。
4. **允许只做一两条**：它从不要求读者全做。我们照抄这个姿态——**这本书是备选单，不是任务清单**。这条要在第 0 章明说。
5. **不给唯一答案**：有争议就摆两边；有适用条件就写出来。
6. **不居高临下**：它像同行者在分享笔记，不像老师在布置作业。

**它的"形"我们不要**：纯条目无过渡（它不做叙事所以能纯条目）、只引期刊论文（制度内容期刊里没有）、密到像技术文档的排版。**我们要主线牵住条目，要引官方文件与法条，要能一页读两条而不憋气。**

---

## 三、人称与姿态

- **对读者说"你"**。禁止"老年人应……""建议老年人……"——把读者推到对面去当研究对象，是机械感的真正来源。
- **禁"我们认为""我们建议"**。作者是整理者，主张一律归给证据或通行做法："通行做法是……""指南里写……""一条能查到的做法是……"。
- 涉及子女视角时切换为"**如果你是在替父母看**"，只写"怎么说出口"和"他不同意时你能做什么"。
- 不用轻慢称呼（老头老太太、银发族）；正文用"你"，叙述他人用"老人""高龄者""失能者"，需要精确时用年龄段。

---

## 四、帮助，而不是指导（本稿新增，最重要的一条）

用户口径：**"站在帮助他的角色，不是指导。"** 这两者在文字上是有判据的，能检查：

| 指导腔（改掉） | 帮助腔（要的） |
|---|---|
| 祈使开头：应该／必须／要／务必／切忌 | 条件开头：如果……那么……／你要做这件事的话，可以这样 |
| "最好的做法是……" | "有人这么做，也有人不这么做；差别在……" |
| 只给答案，不承认代价 | 每条都写"对谁成立""什么时候不成立" |
| 替读者决定 | 把判断权交回去："你自己最清楚"、用提问让读者自己想 |
| 收尾升华一句 | 不总结、不升华 |

**关键区分：给动作 ≠ 指导。** 区别不在有没有动作，而在**谁在决定**。判据是：这条动作是"**你已经决定要做，我告诉你可以怎么做**"（帮助），还是"**我判定你应该做**"（指导）。实现手法：把动作放进**条件之后**或**标题里**，正文写清适用人群与代价。

**连带发现（这条很重要）**：原来看似只是准确性要求的"**必须写适用人群 + 争议栏**"，现在升格为**"不指导"的机制保障**——它等于在每条旁边写上"我不知道你的具体情况，所以这一步由你来判断"。**这一栏不能省，省了就从帮助变成指导。**

**用提问代替判断**（帮助姿态的标志）："你上一次量血压是什么时候？""你测过血里的维生素 D 吗？"——让读者自己去对号，而不是我们替他下结论。

## 五、去 AI 味（可 grep，写稿后机械扫一遍）

**A. 禁用词（出现即改）**
关爱／呵护／温馨／夕阳红／银发族｜赋能／抓手／闭环／颗粒度／生态／链路｜全面／深入／系统／科学／有效／显著／极大地／充分地／至关重要／具有重要意义｜值得一提的是／需要注意的是／综上所述／总而言之／由此可见／不言而喻｜在当今社会／随着……的发展｜让我们／我们不妨／接下来

**B. 禁用句式（出现即改）**

| 禁用 | 为什么 | 改成 |
|---|---|---|
| "不是……而是……"反复出现 | 对举成瘾，最典型的 AI 腔 | 直接说后半句 |
| "不仅……更是……" | 同上 | 拆成两句 |
| 段首"首先／其次／最后" | 三项之间往往没有真实优先级 | 按重要性排，不加序词；真有顺序才用序号 |
| "从 X 到 Y"对称标题 | 对称是为了好看，不是为了说清 | 动作或判断句 |
| 每段结尾拔高一句 | 升华腔 | 删 |
| "因人而异，具体请咨询专业人士"当尾巴 | 免责套话，重复即失效 | 只在制度类内容用一次，且要具体到"咨询谁" |
| "——"作为万能连接 | 破折号滥用 | 换成句号或逗号，全书控制密度 |
| 结尾提问煽动："你准备好了吗？" | 营销腔 | 删 |

**C. 正面替代（不要只说"别这样"，要给出该这样）**

- **用具体代替概括**：不是"注意防滑"，而是"把卫生间那条地垫撤了"。
- **用短句**：一句一个意思，不套从句。
- **少用被动**："被建议"→"有人会告诉你"。
- **敢承认不确定**："这件事没有标准答案""有人适合有人不适合"。
- **敢承认难**："这不是你想看到的，但它是真的。"
- **每章允许一句"承认"**：不带形容词，不安慰，不评价，只把事实说出来。

**D. 判据（防止"娓娓道来"写成水文）**：**每一句要么给动作、要么给事实、要么给承认**。三样都不承担的句子，删掉。这条同时限制了语气词堆砌。

## 六、娓娓道来的七种手法

1. **先说读者现在的处境**："你现在大概是这样——"承认他的状态，再往下说。
2. **给一句能转述的话**（"简单说"栏的用处）：读者读完能说给老伴听。
3. **具体场景开场**：每章用一个具体场景起手（"半夜三点，从马桶上站起来，眼前一黑"），立刻切回说明书体。
4. **短句独立成段**：关键处让一句话单独站着。
5. **把判断交给读者**：用提问收束一节，而不是用结论。
6. **不做总结**：节不硬收尾；每章结尾只给一句"如果你今天只能做一件事"。
7. **平视**：写"我也查不到答案的地方"时如实写；"本章我不确定的地方"是加分项，不是示弱。

## 七、来源与核实（本稿升级为硬规则）

**权威来源放第一位，医疗类尤其。**

1. **有权威来源可用时，一律用权威来源**，不用二手转述、不用营销号、不用"据说"。
2. **来源分级（医疗与照护）**：指南与系统综述 ＞ 官方机构的科普／文件 ＞ 单项研究 ＞ 专家个人意见 ＞ 媒体报道。前两档可直接进正文；单项研究要写明样本与局限；后两档只能当线索。
3. **附出处 + 链接，并逐条核实**：链接要能打开（不能打开就标 `〔待核 N〕`，绝不用一个打不开的链接冒充出处）；**核实动作要真做**，不是引用别人的引用。
4. **标年份**：医疗指南与数据必须写年份（不同年份的指南结论可能相反）。
5. **制度与法律走中国官方文件**（卫健委、医保局、老龄办公报、法条原文），并把法条编号写出来（如《民法典》第 33 条、《深圳经济特区医疗条例》第 78 条）。
6. **医疗内容不写剂量、不做诊断**：只写"去找谁、问什么"。
7. **国际来源与本地可获得性冲突时，两边都写**：某方案在国外是标准做法，但国内不进医保或不易获得——如实说明（这也是本书区别于译作的地方）。

**"如果你是在替爸妈看"这一节的例外**：办法章一律要有（只回答两件事：这句话怎么跟他说出口 / 他不同意时你还能做什么）。**第 0 章、序、结语、附录、以及第 22 章"谢幕之后"不必有**——第 22 章全章本来就是写给家属的，再套一层子女视角是重复。

**引用与版权另有一份专门规范**（`引用与版权规范-v1.md`，含三条红线：连续重合 ≥12 字即算搬运、二手来源必须标"转引"、引文必须加引号并注明译者）；每章写完还要跑 `tools/check_citation.py`。

**两级呈现（解决"权威来源"与"娓娓道来"的冲突）**：
> **正文像人说话，出处像图书馆。** 正文用平实语言，数字句末只挂一个分档角标；链接与完整出处集中在**章末"本章数据来源"**与**附录**，读者想核的时候能核到，不想核也不被打断。

**示范（三条规则同时满足：权威来源 + 承认不确定 + 把判断交回读者）**：
> "维生素 D 和跌倒的关系，结论并不一致：有的系统综述说能降低风险，有的说对已经补够的人没用。【A】(2026-10 核对) 所以真正该问的是——**你测过血里的维生素 D 吗？**"

## 八、条目结构（五栏是上限，不是配额）

```
### 站着穿鞋，比坐着穿鞋更容易摔

- **要花多少**：200–400 元，一次搞定（钱：低｜时间：一次｜体力：低｜面子：零）
- **简单说**：卫生间和玄关是老年家里摔倒最多的两个地方。很多人只装了个灯泡，没装灯。
- 怎么做：① 换鞋凳要有靠背、不带轮；② 旁边墙上装一根竖向扶手；③ 鞋架抬到不用弯腰的高度
- **来源**：B｜通行建议，有跌倒地点分布数据，但没有单项随机试验
- 特别提醒：**对谁成立**——轮椅使用者要的是另一套高度，见 __
- 换回什么 / 解除哪种怕：自理年限｜摔了之后再也起不来
- **在中国怎么落地**：改造补贴见附录 A；自己找人做要问哪三句话，见 __
```

**"轻条目"允许并鼓励**：一句话能说清的事（"把地垫全撤了"）只写"要花多少 + 怎么做 + 来源"。**凑栏位就是形式主义。**

## 九、标题三句式（不许是话题）

- **动作式**：把鞋架抬到不用弯腰的高度／撤掉卫生间那条地垫
- **判断式**：站着穿鞋比坐着穿鞋更容易摔／尿失禁大多数能改善，忍着才是真丢人
- **警告式**：摔之前，身体给过三次提醒／噎住的那一分钟，决定生死

❌ 一律改掉：居家环境改造建议 ｜ 关于用药的注意事项 ｜ 老年心理健康问题探讨 ｜ 关爱老人从细节做起
**章名可以有情绪，节名要朴素**（情绪只在读者需要被叫醒的那一次出现）。
**不用问句当标题**（问句标题是 AI 腔；问句放在正文里做"把判断交给读者"的手法）。

---

## 十、证据分档与案例

**分档**：官方口径 / 第三方研究 / 厂商或机构宣称 / **本书核对**（本书无自测，写清核对日期）/ 未标（计数必须为 0）。
- 只在**关键数字**上用字母，跟一句人话理由：`B｜通行建议，有跌倒地点分布数据，但没有单项随机试验`
- **争议用"但是"起句**，不用"争议："标签
- **"以当地最新口径为准"只在制度类条目出现一次**，用统一角标，不逐条重复

**案例三档**：① 可署名、可给出处（公开报道／官方文件／我们访谈）→ 可进正文；② 无出处的转述 → 只能标"侧写"，**不得当证据**；③ 编的 → 不允许。
**禁合成人物**（"隔壁老王""我的一位患者"）。
**没有真实案例时**：A 优先用公开报道的具名案例 → C 兜底（不要场景，章首只给"这一章解决什么问题"）→ B（标"侧写"）只在极少数必要处使用。

---

## 十一、为"65 岁的人一次读得完"服务的约定

- 一条不超过一屏：五栏全满时控制在 300–400 字。
- 每页条目数克制：宁可一页两条写透，不要一页六条写浅。
- 正文不出现需要读者自己换算的东西：写"一次 200–400 元"，不写"约占月收入 X%"。
- 每章结尾一句"如果你今天只能做一件事"。
- 同一件事全书只有一个名字（统一用"失能评估"，不要一会儿"评定"一会儿"认定"）。

## 十二、风格自检（写稿后机械跑一遍）

1. 禁用词扫描（第五节 A 表）→ 命中数应为 0
2. 禁用句式扫描（第五节 B 表）→ 重点关注"不是……而是……"与段首序词
3. 每条是否写了"对谁成立"→ 缺失即不合格
4. 每条是否有分档角标 → 缺失即不合格；"未标"必须为 0
5. 链接可点性抽检 → 打不开的改 `〔待核 N〕`
6. 是否出现"我们认为／我们建议"→ 应为 0
7. 是否出现祈使句式的"应该／必须"开头（指导腔）→ 逐条判，改成条件句
8. 合成人物扫描（"某位""老王""患者 A"）→ 应为 0

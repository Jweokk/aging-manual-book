调研日期 2026-10-11｜对应《变老说明书》v1.0.0｜原版电子书在本地 `/home/ubuntu/books/`（有版权，不进公开仓库）

## 一、英文原版讲了什么

**书**：*Getting Older: What You Need to Know About Getting Older*（书内简称 *Getting Older*），作者 Lucy Pollock，英国老年科医生（Somerset），Penguin 2020 出版。正文 19 章、约 52 万英文字符（含页眉重复，折合约 8–9 万英文词）；序 + 作者说明 + 尾声 + 致谢。

它要解决的不是"怎么养生"，而是一件更窄的事：**人在变老的路上，怎么把那些说不出口的话说出口，怎么少受罪、少做无效治疗**。作者自己在序里说，这本书是"一次谈话的开始"，不是一本指南。

### 19 章各自在说什么

| 章 | 主题 | 我们书里的对应 |
|---|---|---|
| 1 How to be Old | 还能活多久、这个概率怎么问（英国口径：要到一百多岁，一年内存活概率才降到五成） | 第 1 章（分档核对）、附录 B |
| 2 The Big Questions | 那些"说不出口的大问题"怎么开口；一开口就容易把谈话聊死 | 第 17 章怎么开口 |
| 3 Squaring the Curve | 肌肉、体重、营养、运动、听力能不能"把曲线压平"；认知症风险 | 第 12/13 章 |
| 4 'Good news!' | 老年科是唯一没人主动"点诊"的科室——病人是被转来的，开局就矮一头 | 无（我们的就医红线更硬） |
| 5 Four Things About Falls | 跌倒的四个关口：为什么会跌、药、环境、跌了怎么站起来；住院后功能反而掉 | 第 4 章 |

### 三个方法特征（决定我们该怎么用它）

1. **写法是诊室自述**：作者用自己坐诊的第一人称讲病例，讲到哪算哪，靠故事推进，不靠条目。
2. **案例全部是合成的**。作者在书前 Author's Note 里明说：这些人不是真人，是从许多真实碎片里"编"出来的。也就是说，**她的故事动人，但不能当证据用**——这正好撞上我们定过的案例纪律（禁虚构、合成人物不许写、外部案例只能用可署名公开报道或标"侧写"）。
3. **主张落在"谈话与决定"上，不落制度**。全书反复推的是：把话题打开、先要许可、假定有能力、该减药就减药、该谈预后就谈。至于"钱从哪来、去哪儿办、找谁问"，她基本不写。

### 它没写什么（按全文检索的实感）

| 我们书里有的 | 原版里的分量 |
|---|---|
| 制度与钱（医保、长护险、补贴、手续） | 每章零到 4 处提及，不作为内容 |
| 听力、视力、牙齿 | 近于零 |
| 疫苗、筛查、体检怎么看 | 无 |
| 手机、骗局、数字生活 | 无 |
| 急症红线与送医判断 | 无（她写住院，不写"什么时候必须去"） |
| 身后手续（家属要办什么） | 无 |
| "去哪问、带什么材料" | 无 |

它真正强的地方，是我们写得较薄的那几块：**失禁、谵妄、减药、开车、意思能力与代理人、临终谈话**。这几块值得后续补采时回去看它。

## 二、我们这本书与它的区别

| 维度 | 《Getting Older》 | 《变老说明书》 |
|---|---|---|
| 定位 | 一位老年科医生的谈心书，"一次谈话的开始" | 一份自用查、开源分享的资料汇集，能查、能照做 |
| 读者 | 英国人（NHS、LPA 制度下） | 中国普通人与其子女 |
| 体裁 | 散文＋诊室故事，19 章连续读 | 条目式说明书，22 章＋6 个附录，跳读可查 |
| 案例 | 合成的（作者自述） | 禁虚构；只用可署名公开报道，或用不到 |
| 证据 | 临床经验与叙事为主 | 四档标注（本书核对／通行做法／指南推荐／存疑），数字挂政策文号与核对日期 |
| 制度锚点 | NHS、意思能力法、持久授权书、英国社会照护 | 医保局、卫健委、民政部口径，全国通用＋"问当地" |
| 覆盖强项 | 说不出口的话题 | 制度与钱、就医红线、手续、筛查、数字生活 |
| 更新 | 纸质定版 | 在线站可检索，季度校准＋年度大更 |
| 语言 | 英文 | 中文，去 AI 味，不指导 |

**一句话区别**：她的书是**把话题打开的钥匙**，我们的书是**打开之后照着办的清单**。不冲突，可以互补。

**引用它的三条硬线**：案例不能当证据（合成人物，只能不用或明确标"侧写"）；数字是英国口径（不能当中国数字用）；制度建议不能直接照做。目前正文里已按一手核对引了 3 处（序 p.24、序 p.25、第 20 章 p.264），页码取自电子书纸书锚点，译文自译——这条线保持。

## 三、国内有没有同类内容

有，但分四种，没有一个和我们重合。

### A. 译作与引进书（主流，讲观念）

- 《最好的告别》（Being Mortal，葛文德），浙江人民出版社 2015，豆瓣 9.0，248 页——中文市场这块的标杆，讲衰老、依赖、养老院、临终谈话。
- 《变老之前要知道》——就是 Pollock 这本的中译本，广东人民出版社"万有引力"书系，一熙译，豆瓣 7.9。
- 《百岁生活》（和田秀树 著），海南出版社——日式晚年生活指南。
- 上野千鹤子系列：《一个人的老后》（广西科学技术出版社 2011，豆瓣 7.8）、《一个人最后的旅程》（2021）、《在熟悉的家中向世界道别》（2022）。

共同点：讲谁都会老的道理、讲人生选择，**不落中国的手续、钱、去哪问**。

### B. 国内作者的工具书（最接近我们的形态）

- 《老年实用手册：如何归纳自己的人生》，宗泽亚 编著，中国友谊出版公司 2020-07，豆瓣 7.5——借鉴日本"终活"理念，把老人挂心的事做成表格，附赠密码本、自书遗嘱套装。**这是国内和我们形态最像的一本**（表格化、能填）。
- 《老年慢性病防治与家庭护理 400 问》《吃的误区》《智能手机与生活》《中国老年人防电信网络诈骗指南》《体检报告一看就懂》——点状实用书，各自只覆盖一块，无出处标注。

区别：它们走的是"**整理自己**"（表格、遗嘱、密码本，填完即止、无出处、不更新）；我们走的是"**办事与照护**"（制度口径＋证据分档＋核对日期＋在线更新）。

### C. 官方免费材料（真正的"上游"，也是最大对手）

这些是我们写书时的引用来源，也是读者不买书也能拿到的东西：

特点：**权威、免费，但散在几十个域名和文件里**，没有一份是用读者能用的话写的；多数只覆盖一个器官或一件事（听力一份、膳食一份、跌倒一份）。**这正是我们这本书存在的理由——把它变成索引和动作。**

### D. 开源与自媒体

- **开源：基本是空白。** GitHub 上按"老年 手册／适老化／养老 知识库／老年人 健康 指南"等检索，中文项目里没有同类；搜到的最多是小型实验（"乐龄健康管家"★6、"AI 养老知识库"★0 这类 RAG demo），其余是养老机构的管理软件。**目前没有开源的、面向普通人的中国晚年手册。**
- 自媒体与政务科普：中国老龄协会"银龄在线"、健康中国、各地卫健委科普栏目——量大、更新快，但零散、多数无出处、无版本、读完不知道该干什么。

## 四、结论：我们站在哪个位置

1. 国内**不缺讲观念的书**（译作为主），也**不缺官方材料**（分散、单点），缺的是**把制度、钱、就医、照护、身后事串起来，还能查、能核、能更新的一本**。这是我们唯一的位置。
2. 与最接近的《老年实用手册》的区别：它让你**填完自己的事**；我们让你**知道该找谁、问哪三句、要带什么**。
3. 与译作的区别：它们讲西方经验与人生哲学；我们落中国制度。
4. 与官方材料的区别：我们是官方材料的**索引与翻译**，不是替代。
5. 与自媒体的区别：我们有四档出处标注和核对日期，它们没有。
6. **唯一的真实风险**：我们写制度和钱，就得跟得上政策。落三件事——季度校准的清单里补进「安宁疗护实践指南 2025 年版」「WS/T 875—2026 等 7 项标准（2026-09-01 施行）」「养老服务消费补贴（2026-01-01 全国，每月最高 800 元）」；书末"延伸阅读"里把国内这几类讲清楚（为什么还看我们这本）；英文版可继续引原版，但案例不得当证据。

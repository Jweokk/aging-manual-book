## 这本书在讲什么

变老不是一个瞬间，是分阶段来的：先是身体给信号，接着家里要有人帮，最后是那些一直不想谈的话。这本书按这条时间线排——**五个阶段、22 章正文、6 个附录，约 16 万汉字**。

它不是任务清单。绝大多数条目你一辈子只会用到两三条；**挑一两件做了，这本书就值了。** 剩下的留着备查。

## 怎么用它

- **第一次翻**：从[第 0 章 · 这份说明书怎么用](book/00-第0章-这份说明书怎么用.md)开始，五分钟知道这本书怎么用、每条怎么看。
- **身上有症状**：翻[附录 B · 症状速查表](book/42-附录B-症状速查表.md)——疼、漏、忘、摔，按症状查。
- **有件急事拿不准**：[附录 D · 什么时候必须叫 120](book/44-附录D-叫120判断表.md)。
- **心里有事**：翻[附录 C · 恐惧速查表](book/43-附录C-恐惧速查表.md)——怕变穷、怕拖累子女、怕孤独、怕疼着死。
- **要查制度和钱**：[附录 A · 全国通用制度台账](book/41-附录A.md)——补贴、长护险、医保、殡葬，每条标政策依据和核对日期。
- **想再往下读**：[附录 F · 延伸阅读](book/46-附录F-延伸阅读.md)——叙事与伦理、照护、官方原文。

## 每条怎么看

大多数条目的栏目是固定的：**要花多少**（钱、工夫、力气，还有开不开口）／**简单说**／**可以怎么做**／**来源**／**特别提醒**，末尾两行是**换回来的**和**在中国怎么落地**。有些条目只有三栏——一句话能说清的事，不凑格式。

每个数字后面挂一个证据分档：

- **A**：有具体数字、可公开查到的出处（系统综述、大型研究、法条原文）
- **B**：有研究支持，但给不出确切数字
- **C**：通行做法、经验之谈，不是证据

核不到出处的，正文里明标〔待核〕——首版 14 处。宁可标出来，也不糊过去。

## 边界

- 这本书是**公开资料整理**，**不构成医疗建议**，不代替医生，也不代替你的判断。
- 整理者不装医生、不假装是老人。书里**没有自测数据**：没有一处是我们自己做的实验。
- 不写剂量、不写处方、不做诊断——只写"去找谁、问什么"。
- 与书里提到的任何机构、产品、辅具**无利益关系**。
- 省级细则只写"去找谁问哪三句"，不做 34 省 × 十几项（省级补全是另一轮）。
